# Meet Bansal — Financial Analyst Portfolio

Interactive portfolio showcasing financial valuation modeling, comparative equity research, and technical software engineering projects.

## 🌟 Highlights

- **Featured Research:** Comparative Equity Analysis — *The Coca-Cola Company vs. PepsiCo, Inc. (2022–2024)* featuring DuPont ratio decomposition (ROCE, Gross Margin, Operating Margin, Asset Turnover).
- **Interactive Visualization:** Dynamic financial charting built with Chart.js with metric toggling and analytical commentary.
- **Technical Web Architecture:** Clean responsive UI with Tailwind CSS, glassmorphism, interactive modals, and executive overview panels.
- **Projects:** *Manage Me* — Algorithmic scheduling and academic deadline forecasting web app deployed on Vercel.
